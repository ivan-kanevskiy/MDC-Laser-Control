# MDC-Laser-Control
This project is using weintek MT8072iP for the HMI
  
To create a new execution table, download the template.txt file.
Change the (File to execute box) to the porgram you want to be opened. Leave the quotation marks ("") as they are. The maximum number of characters is 20. 

After you have entered the name of the file you want to open, change the Number box to the number of times you want this specific file to be executed.

The maximum number of loaded programs or columns in the table is 10.
